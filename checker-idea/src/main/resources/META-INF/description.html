MyBatis Mapper Checker verifies that the parameters declared or passed on the Java side match the parameters actually used by the Mapper SQL. Runs on demand and reports results in a tool window; iBatis 2 is supported as well.

检查 MyBatis 项目中 Java 侧声明或传入的参数，与 Mapper SQL 实际使用的参数是否一致。兼容 iBatis 2。

  • Mapper 接口 @Param 声明了、SQL 里却没用的参数
  • Map / Bean 传参时多放的 key，包括由其他方法构造的参数对象
  • 找不到对应 statement 的接口方法或字符串调用
  • 同名 statement 多候选，无法确定目标

手动触发，结果汇总到报告工具窗口，不在编辑器里实时标线。
